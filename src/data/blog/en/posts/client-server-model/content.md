The client-server model is a distributed architecture where responsibilities are split between clients (users) and servers (service providers). This article explains the request–response flow, session management, and common scaling patterns such as load balancing and caching.

## How a request works

A user enters a URL. The browser sends an HTTP request to the server. The server processes the request and returns a response. The browser then renders the result for the user.

## Clients and servers

Clients are user-facing programs that initiate requests. Servers host services, handle data processing, and implement business logic.

## Advantages and drawbacks

This architecture is easy to manage and scale, but servers can become bottlenecks if not properly provisioned or distributed.

**Conclusion:** The client-server model is the foundation of the modern web.
