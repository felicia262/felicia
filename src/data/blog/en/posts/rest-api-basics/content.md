
REST is not a protocol but an architectural style. This article explains RESTful principles, HTTP verbs, status codes, and how to design sensible endpoints.

## REST is more than an API

REST is a way of thinking about system design based on resources.

## Key characteristics

REST is stateless, uses HTTP methods, and commonly exchanges JSON.

## Usage

RESTful APIs connect frontend and backend components in modern systems.

## Practical advice

Design clear endpoints and use HTTP verbs according to their intended semantics.
