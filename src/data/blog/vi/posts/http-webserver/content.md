HTTP là giao thức lớp ứng dụng để truyền các tài liệu siêu văn bản. Bài viết hướng dẫn cấu trúc request/response, headers, status codes, và cách viết một web server đơn giản (ví dụ dùng Node.js hoặc Python).

## HTTP Request gồm gì?

Method, URL, headers và body.

## HTTP Response gồm gì?

Status code, headers và nội dung trả về.

## Vì sao cần hiểu HTTP?

Hiểu HTTP giúp bạn xây dựng web server, API và debug lỗi hiệu quả hơn.

**Kết luận:** HTTP là nền móng của World Wide Web.
