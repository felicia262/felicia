REST không phải là một giao thức mà là một phong cách kiến trúc. Bài này giải thích các nguyên tắc RESTful, HTTP verbs, status codes và cách thiết kế endpoint hợp lý.

## REST không chỉ là API

REST là cách tư duy về thiết kế hệ thống dựa trên tài nguyên.

## Đặc điểm chính

REST stateless, dùng HTTP method và thường trao đổi dữ liệu JSON.

## Ứng dụng

REST API là cầu nối giữa frontend và backend trong hệ thống hiện đại.

## Thực hành

Thiết kế endpoint rõ ràng, dùng HTTP verbs đúng mục đích.
